## 📊 CHEATSHEET (Cola)

### Comandos
```bash
npm run dev      # Servidor local
npm run build    # Build produção
npm install      # Instalar deps
npm cache clean --force  # Limpar cache
```

### Editar Cores
**Arquivo:** `src/styles/global.css` - Procure por `:root`

### Editar Dados
**Arquivo:** `src/pages/Home.tsx` - Procure por `analysisData`

### Editar Textos
**Arquivo:** Qualquer `.tsx` em `src/pages/`

### Adicionar Página
1. Criar em `src/pages/Nova.tsx`
2. Importar em `App.tsx`
3. Adicionar rota
4. Adicionar link em `Header.tsx`
