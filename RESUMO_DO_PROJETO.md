## 🚀 COMO USAR

### 1. Desenvolver Localmente
```bash
npm run dev
# Acesse: http://localhost:3000
```
O site recarrega automaticamente quando você edita arquivos!

### 2. Fazer Build
```bash
npm run build
# Cria pasta dist/ pronta para produção
```

### 3. Ver o Build
```bash
npm run serve
# Visualiza como fica em produção
```
